Receive without Git

Prerequisite: Python 3.11+ with its standard library, including lzma. Inspect and trust the receiver ZIP before unpacking its three Python modules and complete license notices into a new helper directory. Receipt uses no Git, Cargo, pip or network and executes no downloaded source. From the helper directory:

python -I -S -B receive-source.py --archive /downloads/source.tar.xz --sha256 @@SOURCE_SHA@@ --output /new/WITNESS --protect /compiled-target

Use a new output outside the download, helper and compiled-target directories. The receiver bounds archive resources, checks the complete Git commit/tree/file/mode inventory and rejects unsafe paths and links before writing. Existing destinations are preserved. POSIX disk modes are checked on POSIX; Windows preserves the archived mode inventory without claiming equivalent ACLs.

Rebuild from original offline inputs

Install Rust 1.95.0 including wasm32-unknown-unknown, wasm-bindgen CLI 0.2.127 and Python 3.11+ separately. The source contains complete original archives for all 20 locked Cargo dependencies, their 740 original files and complete notices. No compiler or package manager installer is redistributed. Review received code before building it.

From the restored source, choose three new directories outside it for original inputs, Cargo home and compiled output:

python tools/build-pages.py --inputs /new/witness-inputs --cargo-home /new/witness-cargo-home --target /new/witness-target

The builder restores and reads back the owned sources, requires offline locked dependency identities, remaps diagnostic paths, and writes a new dist/WITNESS. The complete package must stay below 5,000,000 bytes. Serve with python -m http.server 8770 --directory dist and open http://localhost:8770/WITNESS/. Direct file opening is not supported.

Validate the result

The native CLI retains plain-text status/replay and structured usage exit code 2. The browser/native-frame control exposes JSON separately. Node 22, the locked npm development dependencies and Playwright Chromium are additional validation prerequisites.

python tools/check-frames.py --site dist/WITNESS --output /new/frame-proof --inputs /new/witness-inputs --cargo-home /new/witness-cargo-home --target /new/witness-target
python tools/check-source-replay.py --site dist/WITNESS --output /new/source-replay --browser

The second command receives the actual delivered source without Git, uses new owned inputs/home and an initially absent target, rebuilds every published file and manifest, then runs native, frame and browser checks. It reuses installed tools and original-checkout development dependencies. Same-platform byte equality is required; cross-platform compiler-byte identity is not promised.
